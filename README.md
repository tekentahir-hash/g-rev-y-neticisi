# 📋 Görev Takip Uygulaması

Günlük, 2 günlük, 3 günlük ve haftalık görevleri takip eden Android uygulaması.

## Özellikler
- ✅ Günlük / 2 günlük / 3 günlük / haftalık görevler
- ⭐ Önemli ve Diğer öncelik ayrımı
- ☑️ Tik atınca görev listeden kalkar
- 🔄 Tamamlanmayanlar ertesi güne otomatik aktarılır

## APK İndirme
GitHub Actions sekmesinden en son build'i indirin.
